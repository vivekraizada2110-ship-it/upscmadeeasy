🔑 AI API Key — needed only for auto-generating questions / mains analysis from PDFs

    
Your key is stored only in this browser's localStorage and is sent directly from your browser to the AI provider. Claude (key from console.anthropic.com) is the recommended provider for question quality. If a model is busy or unavailable, the app retries each sweep with backoff, falls back through alternative models, and lets you re-run only the failed sweeps — no questions are silently skipped, and duplicate questions are automatically removed. Without a key you can still import quiz JSON, use the sample pack, and the full mistakebook + analytics system.

    

      

        
        
        
        
        
        
      

      

        
Quiz JSON Schema

        
{
 "questions":[{
   "q":"question text (UPSC 2023-26 style)",
   "options":["a","b","c","d"],
   "answer": 2,
   "difficulty":"easy|moderate|hard",
   "statements_expl":[{"s":"Statement 1 ...","verdict":"correct|incorrect","why":"one line"}],
   "explanation":"full explanation",
   "topic":"Polity",
   "source":"PDF/page pointer",
   "mains":{"paper":"GS2","syllabus":"...","points":["..."],
            "notes_where":"...","interlinkages":["GS3 — ..."]}
 }]}

      

    

    

      
      
      
    

    
The provider is auto-detected from your key (Claude = sk-ant-…, Gemini = AIza…, OpenAI = sk-…), so a wrong dropdown choice can never break generation. Press ⚡ Test connection once after saving — it tells you instantly whether your key works before you spend a single generation call.

  

  

    
🌐 Make it public / access from anywhere

    
This app is a single HTML file — host it free in 2 minutes and anyone (or you, on any device) can use it. Each visitor's history lives in their own browser's localStorage, and each user enters their own API key.


    Option A — Netlify Drop (easiest): go to app.netlify.com/drop → drag the file (renamed index.html) onto the page → public https link instantly.

    Option B — GitHub Pages: create a repo → upload as index.html → Settings → Pages → deploy from main.


    ⚠️ Data is per-browser-per-device: move it between your phone and laptop with Export backup / Import.
