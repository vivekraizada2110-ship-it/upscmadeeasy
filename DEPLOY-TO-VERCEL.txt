NEW BEHAVIOUR
- Temporary provider errors retry automatically. Two workers overlap retrieval/generation.
- Retry-After guidance is honoured. Exponential retry delay grows to a five-minute ceiling;
  a longer provider-requested wait is honoured. Pause stops retrying and aborts client requests.
- Closing/refreshing preserves dates, source, results, selection, completed questions and queue.
  Reopen the site and log in normally; the saved current-affairs page and unfinished queue restore.
  Generation runs in the open browser, not as an unattended Vercel background job.
- Invalid credentials, payment/access failures or an unavailable model (401/402/403/404) stop safely
  with the reason instead of retrying the same permanent account error indefinitely.
- Existing saved source sets are copied from the old Mapping store on the first current-affairs open.
  Original Mapping data is retained for safety; no automatic destructive migration occurs.
- IndexedDB holds current-affairs state and cached source text/translations; do not clear site data.
- One browser tab owns the current-affairs workspace at a time so stale tabs cannot overwrite progress.
- Delete set, restart set, retry article errors, clear attempt history, and start-over controls confirm
  destructive operations. Clearing history leaves question sets intact.
- Hindi and mixed-language PIB bodies are not rejected. Questions/explanations are English; source
  evidence remains in its original language. Read / translate displays a full English translation,
  cached after the first translation. Generation/translation still require your working AI provider.
- Unreadable/missing releases are labelled with title, date, ID and an exact official link.
- Scanned/image-only PDFs still need OCR; this update does NOT add an OCR engine.
- Optional backup providers are used only if YOU enabled them in shared AI settings. Normal provider
  charges apply. A browser-side abort cannot guarantee the upstream provider stops work/billing.

DATA / SECURITY / LIMITS — PLEASE READ
- Keep the same deployed domain to retain that domain's existing browser storage.
  Study data from another domain or localhost is separate and needs its existing export/import tools.
- Your original entrance screen is preserved. Its client-side password is NOT server authentication.
  Anyone can inspect public frontend assets. For a private website use Vercel Deployment Protection
  or a proper authenticated backend. No claim of production access control is made by the entrance.
- Keys are never hardcoded into the repository or saved by the server-side application code.
  Remembered keys live in browser localStorage, which is not encrypted. Do not use shared browsers.

  many other model endpoints are paid. OpenRouter free-model availability is not guaranteed.

  body limit is reached (the site checks the limit before posting). Non-Gemini PDF batches are capped
  at 12 selected pages; available payload/model limits may require fewer. No document pages are
  silently dropped. Gemini direct requests remain subject to Google's own limits/CORS.

  silently claimed. Source retrieval still depends on upstream government websites.
- Yojana loads the EXACT English issue listed in the official Publications Division public archive.
  That public archive may lag publication. Missing issues are reported, not replaced by another month.
  Upload your English issue PDF if necessary. Scanned pages without extractable text require OCR.
- Other-provider schemas are provided in system instructions; original client validators still reject
  invalid output. Model-generated content is not guaranteed factually perfect.
